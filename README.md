# aula-assincrona-29-10

Instruções

Crie uma página HTML com um formulário que possua:

1.Um campo de entrada para o usuário digitar o nome (ou parte do nome) do livro. Um botão para enviar o formulário.

2.O formulário deve direcionar para uma página PHP chamada buscar.php.

3.Na página buscar.php, recupere o termo de busca do método GET e exiba-o na tela com a mensagem:

"Você buscou pelo livro: [busca]".

Crie uma página HTML com um formulário que possua:

1.Um campo de entrada para o usuário digitar o nome do livro.

2.Um campo de entrada para o usuário digitar o autor do livro. Um botão para enviar o formulário.

3.O formulário deve direcionar para uma página PHP chamada cadastrar.php.

4.Na página cadastrar.php, recupere o nome e o autor do livro do método POST e exiba-os na tela com a mensagem:

5."O livro [nome do livro] escrito por [autor do livro] foi cadastrado com sucesso!"
